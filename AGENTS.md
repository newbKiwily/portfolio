# Portfolio visual conventions

When creating or updating project implementation summary illustrations, follow
`docs/portfolio-visual-style.md` and the approved reference
`assets/gep/explainers/craft.png`. Keep the pixel characters, light background,
mint/amber panels, short Korean labels, and visually explained implementation flow.
Use actual project code as evidence; do not invent implementation details.

The reusable personal image template is
`artifact-template-pixel-portfolio-explainers`.
