# 포트폴리오 구현 설명 그림 — 재사용 스타일

사용자가 2026-10-27 승인한 스타일. 다른 프로젝트의 구현 설명·문제 해결 그림에도 이 스타일을 기본으로 사용한다.

- 개인 템플릿: `$artifact-template-pixel-portfolio-explainers`
- 대표 원본: `assets/gep/explainers/craft.png`
- 생성 프롬프트 모음: `docs/lsp-visual-prompts.md`
- 배경: 흰색 또는 따뜻한 오프화이트 `#fbfaf5`.
- 인물: 제공된 갈색 머리·붉은 스카프 모험가, 파란 마법사, 초록 궁수의 픽셀 디자인.
- 표현: 큰 픽셀 오브젝트, 입력 → 판정/처리 → 결과의 화살표, 전후 비교, 3~4개 시각 패널.
- 색상: 짙은 남색 글자, 민트·앰버 포인트. 장식보다 구현 흐름을 우선한다.
- 텍스트: 짧은 한국어 키워드와 정확한 코드 식별자. 긴 문단은 그림에 반복하지 않는다.
- 정확성: 실제 구현으로 확인한 규칙만 표현한다. 객체 동일성과 아이템 종류, 기능 해금과 오브젝트 생성, 코드상 수치와 테스트 성과를 혼동하지 않는다.
- 배치: 본문에서 그림·UML·결과를 바로 제공한다. 요약 그림은 이전 전체 너비의 65%로 중앙 배치한다.
- UML: 기여는 색상·범례로 표시한다. 스테레오타입은 interface·abstract·struct 등 코드 구조를 설명할 때만 사용한다.
- 개념 그림과 실제 플레이 결과는 명확히 구분한다.
