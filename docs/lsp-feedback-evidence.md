# Little Survival Planet — 기여 표시·플레이 테스트 개선 근거

## 자료 해석

사용자가 제공한 9개 테스트 기록을 확인했다. 파일 번호는 작성일이 아니며,
정확한 테스트 순서·참가자 수·클리어율을 추정하지 않았다.
‘이전 튜토리얼 오류 개선’처럼 명시된 서술만 초기/후속 비교에 사용했다.
피드백과 커밋은 주제별로 대응하며, 특정 의견 때문에 해당 커밋이 만들어졌다고
단정하거나 개선 성공률을 계산하지 않았다. 원문 파일은 저장소에 복사하지 않았다.

## 구조도 표시 원칙

- Personal: 직접 작성한 구현. RecipeItemTypeComparer·SpawnCandidate 등.
- 2026-10-27 사용자 확인 반영: 제작 관련 Comparer·CraftManager·RecipeItemTypeComparer는 Personal로 표시한다. Git상 일부 후속 UI 연결 수정은 별도 팀원 기여로 설명하되 제작 스크립트의 개인 작업 표시는 사용자 확인을 따른다.
- Shared: 양쪽의 기여가 있는 파일. 범례 아래 개인 수정 책임을 별도로 명시한다.
- TeamBase: 팀원 구현을 호출·구독하는 기반. 개인 기능 설명에 보이더라도 개인 구현으로 표시하지 않는다.
- UnityReference: 엔진 타입·API 또는 값/필드/역할 표기. 별도 개인 스크립트로 주장하지 않는다.
- 상태 머신의 기초와 CookingState 등에 추가된 잠금은 서로 다른 기여다.
- SpawnManager의 검증·추첨은 개인 구현이나 이후 공급 주기 조절은 팀원 작업이다.
- Bucket의 기초 Fill/Empty와 후속 스프라이트·인벤토리 갱신 연결도 구분한다.
- 도끼 제작 1회의 벌목 시간 40% 감소는 코드의 0.6 배율이며 사용자 테스트 성과 수치가 아니다.
- 행동 잠금·랜덤 스폰 Troubleshooting은 대응 Core Feature로 통합했다.
- 사운드·미션 결과 UI는 포트폴리오 기여 항목에 추가하지 않았다.

## 본문 시각화 반영

- Little Survival Planet에 한해 추가 설명 팝업을 거치지 않고 Core Features·Troubleshooting 본문에 요약 그림·UML·결과 영상을 직접 배치한다.
- 픽셀 캐릭터는 사용자 제공 레퍼런스를 활용한 개념도이며 실제 게임 화면이 아니다. 실제 플레이 결과 영상은 별도 영역에서 바로 재생한다.
- UML 확대는 선택 기능으로만 제공한다. 핵심 설명을 보기 위한 필수 탐색 단계로 사용하지 않는다.
